03 — Two Colors (Nothing Else)
Government Teal
#0F4C6E
Logo · App icon · Navigation bar · Headings · Primary buttons · Borders
Kashmiri Amber
#E8962E
Fare amounts · Divider line in logo · Call-to-action highlights · Alert badges
The rule: Teal earns institutional trust with commuters and the J&K government. Amber draws the eye to fares and actions — the two things users care about most. White backgrounds only. Never mix both colors on the same element. No third color until you have a design team.

05 — Build the Wordmark in Canva (15 Minutes)
0 min
15 min
1
New design → Custom size: 600 × 260 px
White background. This is your wordmark canvas. Widescreen ratio works for website headers, pitch decks, and app store banners equally.
2
Add text: SAFAR in all caps
Text tool → type SAFAR. Font: search Outfit in Canva fonts. Weight: Bold. Size: 96. Color: #0F4C6E. Letter spacing: +80. Center-align. Position it in the upper-middle of the canvas.
3
Add the amber divider line
Elements → Shapes → Rectangle. Drag a thin rectangle under "SAFAR". Set exact dimensions: W: 200px, H: 4px. Color: #E8962E. Center it horizontally. Gap above and below: ~12px each.
4
Add Urdu text: سفر
New text box → type سفر. Font: search Noto Nastaliq Urdu in Canva. Size: 52. Color: #0F4C6E. If this font isn't in Canva's library, set color to #E8962E and use any Arabic-script font available — the bilingual pairing matters more than the exact font at this stage. Center below the line.
5
Export two versions
Version A: Download → PNG → ✅ Transparent background → filename: safar-logo.png — for app, website, digital.
Version B: Set background to white → Download → PNG → filename: safar-logo-white-bg.png — for documents, pitch deck, print.
